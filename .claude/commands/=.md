# = — 变量赋值

在当前会话中设置临时变量，后续命令可通过 `$变量名` 引用。

## 用法

```
= <变量名>=<值>       → 设置变量
= <变量名>            → 查看变量值
= list                → 列出所有已设置的变量
= clear               → 清除所有变量
```

## 执行方式

1. 解析 `$ARGUMENTS`
2. 判断是赋值、查看、列出还是清除操作
3. 变量存储在会话状态中（不持久化到文件）
4. 返回操作结果

## 示例

```
= base_url=https://api.example.com    → 设置变量
= base_url                             → 查看变量值
= list                                 → 列出所有变量
= clear                                → 清除所有变量
```
