# @ — 智能体快速启动

直接用 `@<agent名>` 启动对应的专业智能体，无需通过 Agent 工具手动指定 subagent_type。

## 用法

```
@<agent名>            → 启动该智能体，自动生成默认任务描述
@<agent名> <描述>     → 启动该智能体并传入指定任务
```

## 内置智能体映射

| 输入 | 映射到 subagent_type | 说明 |
|------|---------------------|------|
| `@debug` | `debug` | 调试专家 — 系统化诊断 bug 和性能回退 |
| `@review` | `code-reviewer` | 代码审查 — 质量、安全、可维护性审查 |
| `@arch` | `architect` | 架构师 — 系统设计与技术决策 |
| `@sec` | `security-auditor` | 安全审计 — OWASP Top 10、注入、SSRF |
| `@perf` | `performance-optimizer` | 性能优化 — 瓶颈分析与优化 |
| `@test` | `test-engineer` | 测试工程 — 测试计划设计与执行 |
| `@refactor` | `refactor-cleaner` | 重构清理 — 死代码消除、结构优化 |
| `@data` | `data-analyst` | 数据分析 — 统计分析、可视化 |
| `@ops` | `devops-engineer` | DevOps — CI/CD、基础设施自动化 |
| `@frontend` | `designer` | 前端开发 — React/Vue/UI 实现 |

## 执行方式

1. 解析 `$ARGUMENTS`，提取第一个词作为 agent 名，其余作为任务描述
2. 在上表查找映射的 subagent_type
3. 调用 `Agent` 工具，传入 `subagent_type` 和 `prompt`
4. 返回智能体的执行结果

## 示例

```
@debug 登录接口返回 500，怀疑是 session 过期处理有问题
@review src/auth/ 目录下的所有文件
@sec 检查支付模块是否存在 SQL 注入风险
@perf 首页加载超过 5 秒，找出瓶颈
```
