# % — 差异对比

快速对比当前工作区文件与另一个文件、分支或提交之间的差异。

## 用法

```
% <文件路径>       → 对比当前文件与另一个文件
% <分支名>         → 对比当前分支与指定分支
% <commit>         → 对比当前与指定提交
% HEAD~1           → 对比与上一个提交
% --staged         → 查看已暂存的变更
```

## 执行方式

1. 解析 `$ARGUMENTS` 获取对比目标
2. 判断目标类型（文件路径/分支/提交/特殊关键字）
3. 执行对应的 git diff 或文件对比
4. 返回格式化差异结果

## 示例

```
% src/auth.ts src/auth.bak.ts    → 对比两个文件
% main                           → 对比当前分支与 main
% HEAD~1                         → 对比与上一个提交
% --staged                       → 查看已暂存变更
```
