# ^ — 结果过滤

对上一条命令或工具的输出结果进行过滤、排序、提取等后处理。

## 用法

```
^ <表达式>           → 对上一步输出进行过滤处理
```

## 支持的表达式

| 表达式 | 说明 | 示例 |
|--------|------|------|
| `grep <模式>` | 过滤匹配行 | `^ grep "error"` |
| `head N` | 取前 N 行 | `^ head 20` |
| `tail N` | 取后 N 行 | `^ tail 10` |
| `sort` | 按字母排序 | `^ sort` |
| `unique` | 去重 | `^ unique` |
| `count` | 统计行数 | `^ count` |
| `json <路径>` | 提取 JSON 字段 | `^ json .data.items` |

## 示例

```
# 上一步列出了 100 个文件
^ grep ".test."              → 只保留测试文件
^ head 20                    → 只看前 20 个
^ count                      → 统计总数
^ unique                      → 去重
```
