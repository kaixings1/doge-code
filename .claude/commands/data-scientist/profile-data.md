# /profile-data — 数据画像报告

生成全面的、可共享的数据画像报告。

## 调用

```
/profile-data [上传文件] 为我们的数据目录剖析此数据集
/profile-data 为营销团队生成画像报告
```

## 工作流

### 步骤 1：加载与剖析
应用 **data-profiling-report** 和 **eda-profile** 技能。

### 步骤 2：生成报告
创建包含模式、质量、统计和建议的利益相关者就绪的 markdown 报告。

### 步骤 3：交付
在工作区中保存为 markdown 文档。

提供后续选项：
- "想要**深入了解**任何具体发现吗？"
- "需要我**生成质量监控**检查吗？"
