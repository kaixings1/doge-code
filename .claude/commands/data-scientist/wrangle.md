# /wrangle — 数据转换工作流

逐步转换、重塑和重构数据。

## 调用

```
/wrangle 将此宽格式调查数据转换为长格式以进行分析
/wrangle 合并这三个表并创建月度聚合
/wrangle [上传文件] 重塑此数据以进行时间序列分析
```

## 工作流

### 步骤 1：理解需求
- 当前数据结构是什么？
- 期望的输出结构是什么？
- 使用什么工具？（pandas, polars, SQL）

### 步骤 2：设计转换
应用 **transform-data** 技能设计转换序列：
- 将当前列映射到目标结构
- 确定需要的重塑操作（透视、逆透视、连接、聚合）
- 处理边界情况（连接产生的空值、重复键、类型冲突）

### 步骤 3：生成并执行代码
- 生成带有注释的、可投入生产的代码
- 在每一步显示中间结果
- 验证输出形状和内容

### 步骤 4：验证
- 确认行数符合预期（特别是在连接后）
- 检查引入的空值
- 通过抽查验证聚合正确性
