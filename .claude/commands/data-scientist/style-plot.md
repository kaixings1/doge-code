# /style-plot — 图表样式

为任何可视化应用专业、可访问的样式。

## 调用

```
/style-plot 为此 matplotlib 图表应用深色主题用于主题演讲
/style-plot 使此图表色盲友好并带有适当的标注
/style-plot 为我的报告中的所有图表创建一致的样式主题
```

## 工作流

### 步骤 1：评估当前状态
审查现有图表代码或描述。

### 步骤 2：应用样式
应用 **style-guide** 技能——颜色、排版、无障碍、布局。

### 步骤 3：交付
带有前后对比的样式化代码。

提供后续选项：
- "想要**将其保存为可复用的主题**吗？"
- "需要我**将此样式**应用于其他图表吗？"
