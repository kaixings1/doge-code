# $ — 快速计算与环境查询

快速执行数学计算或查询环境信息，无需切换到计算器或终端。

## 用法

```
$ <数学表达式>       → 执行计算并返回结果
$ env                → 显示当前环境变量
$ pwd                → 显示当前工作目录
$ os                 → 显示操作系统信息
```

## 计算支�

- 四则运算：`+` `-` `*` `/` `%`
- 幂运算：`**` 或 `^`
- 括号优先级：`( )`
- 常用函数：`sqrt` `abs` `floor` `ceil` `round` `min` `max`
- 常量：`pi` `e`

## 执行方式

1. 解析 `$ARGUMENTS`
2. 如果是 `env`/`pwd`/`os` 等关键字，返回环境信息
3. 否则作为数学表达式计算
4. 返回结果，保留精度

## 示例

```
$ 2 + 2 * 3              → 8
$ (100 - 37) / 3         → 21
$ sqrt(144) + pi         → 15.14159...
$ 1024 * 1024            → 1048576
$ env                    → PATH, HOME, NODE_ENV...
```
