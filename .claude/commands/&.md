# & — 后台异步任务

在后台启动一个长时间运行的任务，不阻塞当前对话。任务完成后自动推送结果。

## 用法

```
& <任务描述>       → 在后台启动任务
&                  → 查看当前后台任务状态
```

## 适用场景

- 大型代码库分析（`& 分析整个项目的依赖关系`）
- 长时间构建/测试（`& 运行全量测试套件`）
- 批量文件操作（`& 重命名所有废弃的 API 端点`）
- 文档生成（`& 生成 API 文档`）

## 执行方式

1. 解析 `$ARGUMENTS` 获取任务描述
2. 使用 `TaskCreate` 创建后台任务
3. 立即返回任务 ID，不等待完成
4. 任务完成后通过 `TaskOutput` 获取结果

## 输出格式

```
⏳ 后台任务已启动

任务 ID：xxx
描述：分析整个项目的依赖关系
状态：进行中

使用 & 查看所有后台任务状态。
```

## 示例

```
& 分析项目所有模块的依赖关系
& 运行 e2e 测试并生成报告
& 重构 utils 目录下的所有函数
```
