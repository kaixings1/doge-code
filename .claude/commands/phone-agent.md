# Phone Agent — 手机自动化控制

基于 Open-AutoGLM 框架的手机自动化命令。

## 子命令
- `start` — 启动 Phone Agent 连接设备
- `stop` — 停止 Phone Agent
- `exec <instruction>` — 执行自然语言指令
- `screenshot` — 截取当前屏幕
- `tap <x> <y>` — 点击坐标
- `swipe <x1> <y1> <x2> <y2>` — 滑动操作
- `input <text>` — 输入文本
- `home` — 返回桌面
- `back` — 返回上一级
- `open <app>` — 打开应用
