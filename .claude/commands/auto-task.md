## 用户输入

```text
`$ARGUMENTS
```

## 执行模式

你处于全自动模式。必须自主完成所有步骤，不向用户确认。

## 执行流程

### 阶段 1：任务分析

理解用户需求，分解为原子级子任务，明确依赖关系。

### 阶段 2：子任务创建

使用 TaskCreate 工具为每个子任务创建任务项。

### 阶段 3：并行执行

使用 AgentTool 执行子任务，无依赖的任务可并行执行。

### 阶段 4：验证

检查所有子任务输出，运行编译测试验证。

### 阶段 5：汇总

输出完成报告，标记所有 TaskCreate 任务为完成。

##  重要规则

1. 不询问用户：所有决策自主完成
2. 使用 TaskCreate：为每个可独立验证的工作单元创建任务
3. 使用 AgentTool：复杂子任务交给子代理执行
4. 出错自动修复
