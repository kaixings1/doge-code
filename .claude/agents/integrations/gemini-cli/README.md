# Gemini CLI 集成

所有 61 个 Agency 代理已合并到单个 `GEMINI_AGENTS.md` 文件中。

## 安装

```bash
# 从项目根目录运行
cd /your/project
/path/to/agency-agents/scripts/install.sh --tool gemini-cli
```

## 激活代理

在 Gemini CLI 中引用代理：

```
使用安全工程师代理审计此配置。
```

## 重新生成

```bash
./scripts/convert.sh --tool gemini-cli
```
