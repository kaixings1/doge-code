# New Relic 自动化

自动执行 New Relic 可观察性工作流——创建和管理告警策略、配置通知渠道（邮件、Slack、Webhook、PagerDuty）、监控 APM 应用、检查告警条件，并将 New Relic 告警集成到跨应用管道中。
