# Jotform 自动化

通过自然语言自动执行 Jotform 工作流。

## 核心能力

- 表单列表和搜索
- 用户和权限管理
- 表单提交和活动历史
- 文件夹组织
- 订阅计划检查

## 使用前提

- 需要 Rube MCP 服务器已连接
- 通过相关连接工具建立 Jotform 连接
- 使用前先搜索可用工具

## 使用方式

直接使用自然语言描述任务：
- "列出我所有的表单"
- "找到上个月的提交记录"
- "将表单移动到指定文件夹"
- "检查当前订阅计划"
**工具包文档:** [composio.dev/toolkits/jotform](https://composio.dev/toolkits/jotform)
