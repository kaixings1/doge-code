# JobGPT - 求职自动化

## 概述

JobGPT 通过 JobGPT MCP 服务器将您的 AI 助手连接到完整的求职自动化平台。

## 何时使用此技能

- 搜索职位
- 自动申请职位
- 生成定制简历
- 跟踪求职申请
- 寻找招聘人员
- 导入职位
- 查询薪酬

## 设置

1. 确保 JobGPT MCP 服务器已配置并运行
2. 使用 `RUBE_MANAGE_CONNECTIONS` 或等价工具建立连接
3. 配置求职偏好（职位类型、地点、薪资范围）
4. 上传您的简历作为基础模板

## 示例

### 查找远程职位

```
按月搜索 12k-18k 的前端工程师远程职位
筛选条件：React/Vue，3 年以上经验
```

### 自动申请职位

```
根据我的简历自动申请匹配的前端工程师职位
条件：与我的技术栈匹配度 > 80%
备注：已有 3 年 React 经验
```

### 生成定制简历

```
为以下岗位生成定制简历：
- 职位：高级全栈工程师
- 公司：字节跳动
- 重点强调：Node.js 和微服务经验
```

### 从 URL 导入并申请

```
从以下 URL 导入职位并申请：
https://jobs.company.com/posting/12345
```

### 招聘人员外展

```
搜索科技行业的招聘人员
条件：专注互联网行业，主动联系
提供我的简历和求职意向
```

### 查看申请统计信息

```
显示过去 30 天的申请统计数据
包括：已投递、已查看、面试邀请、被拒
```

## 最佳实践

- 简历模板保持更新，突出最新技能
- 开启自动申请前先测试匹配精度
- 设置每日申请上限，避免过度投递
- 定期查看申请状态，及时回复招聘方
- 薪酬信息仅供参考，实际谈判时灵活调整
- 不要同时申请同一家公司的多个雷同岗位

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| MCP 连接失败 | 检查服务器地址和端口，确认服务正在运行 |
| 职位搜索无结果 | 检查关键词拼写，放宽筛选条件 |
| 简历生成格式错误 | 确认上传的简历为支持的格式 |
| 自动申请未执行 | 检查是否已登录平台账户，确认匹配阈值设置 |
| 薪酬数据不准确 | 数据来源于公开信息，建议结合多个来源验证 |
