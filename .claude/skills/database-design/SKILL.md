## 反模式

❌ 为简单应用默认使用 PostgreSQL（SQLite 可能足够）
❌ 跳过索引
❌ 在生产环境中使用 SELECT *
❌ 当结构化数据更好时存储 JSON
❌ 忽略 N+1 查询
