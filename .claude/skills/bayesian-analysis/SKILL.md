# 贝叶斯分析

## 目标
应用贝叶斯推理来估计参数、比较模型，并以自然概率表述在不确定性下做出决策。

## 工作原理

### 第一步：构建模型
- 定义似然函数（数据生成过程）
- 选择先验分布（信息性、弱信息性、非信息性）
- 指定感兴趣的参数

### 第二步：计算后验
- **共轭先验**：闭式后验（Beta-Binomial、Normal-Normal）
- **MCMC**：复杂模型使用 PyMC、Stan、NumPyro
- **变分推断**：大数据集的近似后验
- 诊断：迹线图、R-hat、有效样本量、发散情况

### 第三步：汇总结果
- 后验均值、中位数、众数
- 可信区间（HDI — 最高密度区间）
- 后验预测检查
- 假设概率（P(θ > 0 | 数据)）

### 第四步：模型比较
- 贝叶斯因子
- 预测性能的 WAIC、LOO-CV
- 后验预测检查

## 使用示例

```
"运行贝叶斯 A/B 测试 — 1000 位访客看到变体 A（50 人转化），
1200 位看到变体 B（72 人转化）。B 更好的概率是多少？"
```

```
"用贝叶斯模型估计流失率 — 我们基于历史数据认为
大约是 5%"
```

## 输出格式

- **后验汇总**：每个参数的均值、中位数、HDI
- **可视化**：后验分布、迹线图、森林图
- **概率表述**：P(假设 | 数据) 以通俗语言呈现
- **Python 代码**：PyMC / arviz 实现
