# 着陆页生成器

根据产品描述生成高转化率的着陆页。输出完整的 Next.js/React 组件，包含多个区块变体、经过验证的文案框架、SEO 优化和性能优先模式。不是 lorem ipsum——而是真正能转化的文案。

**目标：** LCP < 1s · CLS < 0.1 · FID < 100ms  
**输出：** TSX 组件 + Tailwind 样式 + SEO 元数据 + 文案变体

## 何时使用
- 需要生成 Next.js 或 React 营销着陆页时。
- 任务涉及以转化为中心的页面结构、区块变体、Tailwind 样式或 SEO 感知文案。
- 想要从产品描述生成完整的着陆页输出，而非孤立的 UI 片段。

## 核心能力

- 5 种 Hero 区块变体（居中、分割、渐变、视频背景、极简）
- 功能区块（网格、交替、带图标的卡片）
- 定价表（2-4 层级，含功能列表和切换）
- FAQ 手风琴（含 架构 标记）
- 客户评价（网格、轮播、单条引用）
- CTA 区块（横幅、全页、内联）
- 页脚（简单、大型、极简）
- 4 种设计风格（带 Tailwind 类集）
