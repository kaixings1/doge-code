# Review Resume

## Purpose
Review and improve data science resumes using proven best practices.

## How It Works

### Assessment Criteria
1. **Impact quantification**: Use XYZ formula (Accomplished [X], as measured by [Y], by doing [Z])
2. **Technical skills**: Relevant tools, languages, frameworks prominently listed
3. **Project descriptions**: Problem → approach → result, not just tool usage
4. **Structure**: Clean format, scannable, 1-2 pages
5. **Keywords**: ATS-optimized for target role
6. **Consistency**: Tense, formatting, date format

### Common Issues
- Listing tools without showing impact
- Missing quantified results
- Too long or too dense
- Irrelevant experience not trimmed
- No GitHub/portfolio link

## Usage Examples

```
"Review my data science resume — I'm targeting senior DS roles at tech companies"
```

## Output Format

- **Score**: Overall rating with dimension breakdowns
- **Strengths**: What's working well
- **Improvements**: Specific, actionable suggestions with rewritten bullets
- **Keywords**: Missing keywords for target roles
