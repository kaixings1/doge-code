--- # 撰写报告 ## 目标
为不同受众构建清晰、可操作的分析报告。 ## 报告结构 ### 1. 执行摘要（1 页）
- 一句话关键发现
- 建议
- 预期影响 ### 2. 背景与目标
- 业务背景和问题陈述
- 本分析要回答的问题
- 范围和限制 ### 3. 方法论
- 数据来源和时间段
- 分析方法
- 关键假设 ### 4. 发现
- 以洞察为先，而非数据
- 使用带洞察驱动标题的图表
- 渐进式详细（概览 → 深度挖掘） ### 5. 建议
- 优先级明确、可操作、具体
- 预期影响量化
- 所需资源和时间线 ### 6. 附录
- 详细方法论
- 额外图表和表格
- 数据质量说明 ## 使用示例 "为执行团队撰写一份关于我们 Q4 流失分析的分析报告" ## 输出格式 - **报告模板**：包含所有章节的 Markdown 文档
- **图表建议**：应包含的可视化类型
- **执行摘要**：独立单页摘要
