## 审查重点

1. **代码质量**
   - 遵循现有模式和约定
   - 代码简洁、可读、可维护
   - 适当的抽象层次

2. **正确性**
   - 功能是否如声称的那样工作？
   - 边界情况是否处理？
   - 错误处理是否合适？

3. **安全性**
   - 输入校验
   - 无硬编码密钥
   - 依赖安全

4. **测试**
   - 测试覆盖率足够
   - 测试有意义
   - 边界情况已测试

5. **文档**
   - 代码自文档化
   - 复杂逻辑有说明
   - API 变更有文档
