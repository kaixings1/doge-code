# Go 并发模式

Go 并发编程的生产模式，包括 goroutine、channel、同步原语和 context 管理。

## 使用此技能的场景

- 构建并发 Go 应用程序
- 实现工作池和管道模式
- 管理 goroutine 生命周期
- 使用 channel 进行通信
- 调试竞态条件
- 实现优雅停机

## 不要使用此技能的场景

- 任务与 Go 并发模式无关
- 需要此范围之外的不同领域或工具
