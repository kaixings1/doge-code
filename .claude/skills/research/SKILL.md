name: 针对高可信原始来源调查一个问题，并将发现结果以 Markdown 文件形式保存在
description: 针对高可信原始来源调查一个问题，并将发现结果以 Markdown 文件形式保存在仓库中。当用户需要对某个主题进行研究、收集文档或 API 事实、或将文献查找工作委托给后台代理时使用。
--- 启动一个**后台代理**来完成研究，这样你就可以在它阅读时继续工作。 它的任务： 1. 针对**原始来源**调查问题 — 官方文档、源代码、规范、第一方 API — 而不是对它们的二次撰写。将每个主张追溯到其来源。
2. 将发现写入一个 Markdown 文件，引用每个主张的来源。
3. 将其保存在仓库已有的笔记位置；遵循现有约定，如果不存在约定，则放在合理的位置并说明在哪里。
