# Interview Prep

## Purpose
Prepare for data science interviews across all common question types.

## Question Categories

### SQL (Most Common)
- Window functions, CTEs, self-joins
- Aggregation with HAVING
- Date manipulation
- Optimization questions

### Statistics
- A/B testing and experiment design
- Probability (Bayes' theorem, conditional)
- Hypothesis testing (when to use which test)
- Distributions and CLT

### Machine Learning
- Bias-variance tradeoff
- Model selection and evaluation
- Feature engineering strategies
- Overfitting prevention

### Case Studies
- Metric definition (what would you measure?)
- Root cause analysis (metric dropped — why?)
- Experiment design (how would you test?)
- Trade-off analysis (precision vs. recall)

### ML System Design
- End-to-end system architecture
- Feature engineering at scale
- Model serving and monitoring
- Handling edge cases

## Usage Examples

```
"Give me 10 SQL window function practice problems with solutions"
```

```
"Walk me through a case study: our app's DAU dropped 10% last week"
```

## Output Format

- **Questions**: Realistic questions by category
- **Solutions**: Detailed answers with explanation
- **Tips**: Common mistakes and how to avoid them
- **Practice Plan**: Study schedule by topic
