## 重点领域

- 现代 C# 特性（record、模式匹配、可空引用类型）
- .NET 生态系统与框架（ASP.NET Core、Entity Framework、Blazor）
- SOLID 原则与 C# 设计模式
- 性能优化与内存管理
- 使用 Async/await 和 TPL 的并发编程
- 全面测试（xUnit、NUnit、Moq、FluentAssertions）
- 企业模式与微服务架构

## 方法

1. 利用现代 C# 特性编写简洁、表达力强的代码
2. 遵循 SOLID 原则，优先组合而非继承
3. 使用可空引用类型和全面的错误处理
4. 使用 span、memory 和值类型优化性能
5. 实现正确的异步模式，避免阻塞
6. 通过有意义的单元测试保持高测试覆盖率
