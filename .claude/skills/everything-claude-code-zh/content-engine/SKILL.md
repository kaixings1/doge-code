# 内容引擎

将一个想法转化为强大的、平台原生的内容，而不是在所有地方发布同样的东西。

## 何时激活

- 编写 X 帖子或推文串
- 起草 LinkedIn 帖子或发布更新
- 编写短视频或 YouTube 讲解视频脚本
- 将文章、播客、演示或文档重用为社交内容
- 围绕发布、里程碑或主题构建轻量级内容计划

## 首要问题

澄清以下内容：
- 来源资产：我们要从什么内容进行适配
- 受众：开发者、投资者、客户、运营者或普通受众
- 平台：X、LinkedIn、TikTok、YouTube、时事通讯或多平台
- 目标：知名度、转化、招聘、权威性、发布支持或互动

## 核心规则

1. 针对平台进行适配。不要跨平台发布相同的文案。
2. 钩子比摘要更重要。
3. 每条帖子应承载一个清晰的想法。
4. 使用具体的细节而非口号。
5. 保持行动号召（ask/CTA）小而清晰。

## 平台指南

### X
- 快速切入
- 每条帖子或推文串中的每条推文只包含一个想法
- 除非必要，否则不要在正文中放入链接
- 避免标签堆砌

### LinkedIn
- 强有力的第一行
- 短段落
- 围绕经验教训、结果和收获进行更明确的框架构建

### TikTok / 短视频
- 前 3 秒必须抓住注意力
- 围绕视觉效果编写脚本，而不只是旁白
- 一个演示，一个主张，一个行动号召（CTA）

### YouTube
- 尽早展示结果
- 按章节组织结构
- 每 20-30 秒刷新一次视觉效果

### 时事通讯
- 提供一个清晰的视角，而不是一堆无关项的集合
- 使各节标题易于扫描
- 让开头段落发挥实际作用

## 重用流程

默认级联步骤：
1. 锚点资产：文章、视频、演示、备忘录或发布文档
2. 提取 3-7 个原子创意
3. 编写平台原生变体
4. 削减输出中的重复内容
5. 使行动号召与平台意图保持一致

## 交付物

当被要求策划活动时，返回：
- 核心视角
- 平台特定的草案
- 可选的发布顺序
- 可选的行动号召（CTA）变体
- 发布前所需的任何缺失输入

## 质量关卡

在交付前：
- 每个草案读起来都符合其平台的原生风格
- 钩子强有力且具体
- 没有通用的炒作语言
- 除非要求，否则不同平台之间没有重复文案
- 行动号召（CTA）与内容和受众匹配
