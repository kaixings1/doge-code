# D3 可视化

> 精选自 @jiannanya。

## 功能说明

教导代理生成 D3 图表和交互式数据可视化。一个全面的 D3.js 技能，涵盖各种图表类型和技术的示例，赋予代理专家级知识以生成复杂的交互式可视化。适用于编辑仪表盘、报告、数据密集型原型和说明性图形。

## 来源

- 上游：https://github.com/jiannanya/snow-d3/
- 分类：`diagrams`

## 使用方法

此目录条目在开放设计中宣传该技能，以便代理在规划期间发现它。要运行完整的上游工作流及其原始资产、脚本和参考文档，请将上游包安装到您的活动代理技能目录中：

```bash
# 查看上游 README 了解确切路径
open https://github.com/jiannanya/snow-d3/

# 将 snow-d3/ 文件夹克隆或复制到工作区的 skills/ 目录中
git clone https://github.com/jiannanya/snow-d3.git skills/snow-d3

```

然后要求代理按名称（`d3-visualization`）或使用此技能 frontmatter 中列出的触发短语调用此技能，例如：

> "为我的销售数据创建一个可缩放的树图"
> "构建一个力导向网络图，类似示例 07，但使用我自己的数据集"
> "在 D3 中生成一个日历热力图"
