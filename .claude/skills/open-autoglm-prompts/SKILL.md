# Open-AutoGLM 提示词系统

智谱清言 Open-AutoGLM 的手机自动化提示词，用于 AI 控制 Android/iOS 设备。

## 提示词结构
- system_prompt：系统级行为定义
- 操作分类：点击/滑动/输入/截图/应用管理
- 设备类型：Android（ADB）/ iOS（XCTest）/ HarmonyOS

## 核心操作
- 屏幕点击与手势
- 文本输入
- 应用启动/关闭
- 截图与 UI 分析
- 坐标定位
