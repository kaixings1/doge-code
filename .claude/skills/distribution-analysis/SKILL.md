# 分布分析

## 目标
描述数据的统计分布特征。判断数据是否正态分布，识别最佳拟合分布，并根据分布形状提供合适的统计工具。

## 工作原理

### 第一步：可视化评估
- 带 KDE 叠加的直方图
- 与正态分布对比的 QQ 图
- 带异常值标记的箱线图
- ECDF（经验累积分布函数）

### 第二步：正态性检验
- Shapiro-Wilk 检验（n < 5000 时最佳）
- D'Agostino-Pearson 检验（结合偏度和峰度）
- Anderson-Darling 检验（对尾部敏感）
- Kolmogorov-Smirnov 检验（通用拟合优度）

### 第三步：分布拟合
拟合候选分布并按拟合优度排序：
- 正态、对数正态、指数、Gamma、Beta、Weibull、泊松、均匀
- 候选分布的 AIC/BIC 比较
- 含置信区间的拟合参数

### 第四步：转换建议
如果非正态：
- 对数转换（右偏数据）
- Box-Cox 转换（最优幂转换）
- Yeo-Johnson 转换（处理负值）
- 平方根转换（计数数据）

### 第五步：实际影响
- 哪些统计检验适用（参数 vs. 非参数）
- 对置信区间和假设检验的影响
- 建模建议（GLM 族选择、核选择）

## 使用示例

```
"这个收入数据是正态分布的吗？应该应用什么转换？"
```

```
"为这个事件时间数据拟合最佳分布以供模拟建模"
```

## 输出格式

- **可视化摘要**：直方图、QQ 图、箱线图
- **检验结果**：正态性检验 p 值及解释
- **最佳拟合**：分布名称、参数、拟合优度指标
- **转换建议**：推荐的转换方法及前后对比
- **Python 代码**：可复现的分析脚本
