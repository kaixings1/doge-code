# Godot GDScript 模式

Godot 4.x 游戏开发中使用 GDScript 的生产模式，涵盖架构、信号、场景和优化。

## 使用此技能的场景

- 使用 Godot 4 构建游戏
- 在 GDScript 中实现游戏系统
- 设计场景架构
- 管理游戏状态
- 优化 GDScript 性能
- 学习 Godot 最佳实践

## 不要使用此技能的场景

- 任务与 Godot GDScript 模式无关
- 需要此范围之外的不同领域或工具
