# 演示设计

## 目的
使用金字塔原理设计驱动决策的数据演示。

## 工作原理

### 幻灯片结构（金字塔原理）
1. **推荐幻灯片**：以结论开头
2. **证据幻灯片**：2-3 个支撑发现
3. **细节幻灯片**：问答环节备用（附录）

### 设计规则
- 每张幻灯片一个信息
- 图表标题 = 洞察，而非指标
- 每张幻灯片最多 3-4 个要点
- 使用渐进式披露（逐步构建复杂图表）
- 全程保持一致的样式

### 受众适配
- **高管**：5 张幻灯片，清晰的推荐方案，ROI
- **同行**：10-15 张幻灯片，方法论 + 发现
- **技术受众**：完整的方法论、代码、假设

## 使用示例

```
"Design a 10-slide presentation of our customer segmentation analysis"
```

## 输出格式

- **幻灯片大纲**：带关键消息的结构
- **图表规格**：每张幻灯片的可视化内容
- **演讲者备注**：谈论要点和过渡
