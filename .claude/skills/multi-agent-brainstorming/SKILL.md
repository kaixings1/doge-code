# 多代理头脑风暴（结构化设计评审）

## 目的

将单代理设计转变为**经过评审验证的健壮设计**，通过使用多个约束代理模拟正式同行评审过程。

此技能旨在：
- 揭示隐藏假设
- 早期识别故障模式
- 验证非功能约束
- 在实施前对设计进行压力测试
- 防止想法混乱

这不是**并行头脑风暴**。
这是**带强制角色的顺序设计评审**。
