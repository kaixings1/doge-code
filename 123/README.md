# Node.js Hello World HTTP Server
这是一个基于 Node.js 原生 `http` 模块实现的轻量级 HTTP 服务器，监听本地 `3000` 端口，对所有请求返回 `Hello World` 响应，无任何第三方依赖。

## 功能特性
- 监听本地 `3000` 端口
- 所有 HTTP 请求均返回状态码 `200` + `Hello World` 文本响应
- 基于 Node.js 原生模块，无需安装额外依赖即可运行

## 环境要求
- Node.js >= 14.x（推荐使用 LTS 版本）
- npm（随 Node.js 安装自带）
