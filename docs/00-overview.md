  1. 项目简介


  1.1 项目名称与定位


  Doge Code 是一个基于 Claude Code 的中文定制 Fork，定位为生产级 AI 编程助手 CLI 工具。它不是一个简单的命令行包装器，而是一个完整的 AI Agent 系统，具备：

  - 完整的中文本地化：系统提示词、UI 文本、错误信息全面汉化
  - 多 Provider 支持：78+ 预设 API 配置，支持 Anthropic/OpenAI/中国AI/Gateway/Local 等多类 Provider
  - 协议转换层：OpenAI Chat Completions ↔ Anthropic Messages 双向转接
  - 可扩展架构：插件系统、技能系统、MCP 集成、自定义命令
  - 独立可执行文件：通过 Bun 编译为 doge.exe，零依赖部署

  2. 核心特性


  2.1 查询引擎


  状态机驱动的消息循环：

  idle → responding → needs_user → should_continue → done/crashed/aborted

  核心能力：
  - 流式响应处理（SSE/WebSocket）
  - 工具调用调度与结果处理
  - Token 预算控制与自动压缩
  - 错误恢复与重试机制
  - 子代理查询执行

  2.2 API 双向支持


  双客户端架构：

  ┌─────────────────┐    ┌──────────────────┐
  │ Anthropic API   │    │   OpenAI API     │
  │ (Claude Models) │    │ (GPT Models)     │
  └────────┬────────┘    └─────────┬────────┘
           │                       │
      ┌────┴───────────────────────┴────┐
      │         Bridge Layer            │
      │  (Protocol Conversion)          │
      └────────────────┬────────────────┘
                       │
           ┌───────────┴───────────┐
           │   Unified Client      │
           │   (Bootstrap Choice)  │
           └───────────────────────┘

  Bridge 层职责：
  - OpenAI Chat Completions → Anthropic Messages（请求转换）
  - Anthropic Messages → OpenAI Chat Completions（响应转换）
  - SSE 流式传输适配
  - 会话轮询与状态同步
  - 错误映射与重试策略

  3. 启动流程


  3.1 入口链


  bun run doge
      ↓
  bootstrap-entry.ts
      ↓ 读取 ~/.doge/api.json 或 .doge/api.json
      ↓ 设置环境变量（ANTHROPIC_API_KEY 等）
      ↓ 导入 CLI 入口
  entrypoints/cli.tsx
      ↓ 解析 CLI 参数
      ↓ 快速路径判断
      ↓ 启动 Ink TUI
  main.tsx (init)
      ↓ 初始化 GrowthBook（特性开关）
      ↓ 初始化遥测服务
      ↓ 初始化策略限制
      ↓ 加载技能/插件/MCP
      ↓ 启动 QueryEngine
  query.ts
      ↓ 进入主消息循环

  7. 快速开始


  7.1 安装


  # 克隆仓库
  git clone https://github.com/user/doge-code.git
  cd doge-code

  # 安装依赖
  bun install

  # 注册全局命令
  bun link

  7.2 配置 API


  创建 ~/.doge/api.json：

  {
    "activePreset": "claude-3-5-sonnet",
    "presets": {
      "claude-3-5-sonnet": {
        "provider": "anthropic",
        "apiKey": "YOUR_API_KEY",
        "model": "claude-3-5-sonnet-20241022"
      }
    }
  }

  7.3 运行


  # 开发模式
  bun run dev

  # 生产模式
  doge

  # 调试模式
  d.bat
