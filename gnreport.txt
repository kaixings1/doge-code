  关键趋势洞察


  1. 自主性竞赛：Devin > Claude Code ≈ Cursor Agent ≈ Windsurf Cascade > Copilot Agent > Aider > Bolt/v0
  2. 定价策略分化：Windsurf 主打"免费补全 + 低价 Agent"；Cursor 走"AI-native IDE"订阅；Copilot 走 GitHub 生态绑定；Amazon Q 走 AWS 生态绑定
  3. 架构趋势：从"代码补全" → "对话式编程" → "自主 Agent 循环" → "多 Agent 并行协作"
  4. 隐私与合规：Windsurf（零数据留存）、Aider（完全离线/自托管）、Amazon Q（VPC 部署）在企业市场各有优势
  5. 生态锁定：GitHub（Copilot）、AWS（Amazon Q）、Vercel（v0.dev）都在通过 AI 工具加深生态绑定

  关键结论


  1. 开源替代已经成熟：OpenHands 和 SWE-agent 在 SWE-bench 上已经接近商业级（Devin）
  2. 自主性分层：Devin > OpenHands ≈ Cursor Agent > Claude Code ≈ Aider > Copilot
  3. 隐私/合规需求选开源：OpenHands + 本地模型（Ollama/Llama）可实现完全离线
  4. 学术研究选 SWE-agent：可复现、轻量、benchmark 标准化
  5. VS Code 用户选 Cline：零成本、功能全、社区活跃
