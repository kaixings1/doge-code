# Presentation Design

## Purpose
Design data presentations that drive decisions using the Pyramid Principle.

## How It Works

### Slide Structure (Pyramid Principle)
1. **Recommendation slide**: Lead with the answer
2. **Evidence slides**: 2-3 supporting findings
3. **Detail slides**: Backup for Q&A (appendix)

### Design Rules
- One message per slide
- Chart title = the insight, not the metric
- Maximum 3-4 bullet points per slide
- Use progressive disclosure (build complex charts step by step)
- Consistent styling throughout

### Audience Adaptation
- **Executives**: 5 slides, clear recommendation, ROI
- **Peers**: 10-15 slides, methodology + findings
- **Technical**: Full methodology, code, assumptions

## Usage Examples

```
"Design a 10-slide presentation of our customer segmentation analysis"
```

## Output Format

- **Slide Outline**: Structure with key messages
- **Chart Specifications**: Visualization per slide
- **Speaker Notes**: Talking points and transitions
