# Document Analysis

## Purpose
Write clear documentation for analyses and models that enables reproducibility and knowledge transfer.

## Documentation Types

### Analysis README
- Problem statement and business context
- Data sources and access instructions
- How to reproduce the analysis
- Key findings summary

### Model Card
- Model details (type, version, training data)
- Intended use and limitations
- Evaluation results and fairness assessment
- How to use for inference

### Data Dictionary
- Column descriptions, types, and valid values
- Data lineage (where does it come from?)
- Known issues and caveats
- Update frequency

## Usage Examples

```
"Write a model card for our production churn prediction model"
```

## Output Format

- **Documentation**: Formatted markdown document
- **Templates**: Reusable templates for future use
