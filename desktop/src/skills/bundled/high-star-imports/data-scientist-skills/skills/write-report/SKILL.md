# Write Report

## Purpose
Structure clear, actionable analytical reports for different audiences.

## Report Structure

### 1. Executive Summary (1 page)
- Key finding in one sentence
- Recommendation
- Expected impact

### 2. Background & Objective
- Business context and problem statement
- Questions this analysis answers
- Scope and limitations

### 3. Methodology
- Data sources and time period
- Analytical approach
- Key assumptions

### 4. Findings
- Lead with insights, not data
- Use charts with insight-driven titles
- Progressive detail (overview → deep-dive)

### 5. Recommendations
- Prioritized, actionable, specific
- Expected impact quantified
- Required resources and timeline

### 6. Appendix
- Detailed methodology
- Additional charts and tables
- Data quality notes

## Usage Examples

```
"Write an analytical report on our Q4 churn analysis for the executive team"
```

## Output Format

- **Report Template**: Markdown document with all sections
- **Chart Recommendations**: Which visualizations to include
- **Executive Summary**: Standalone one-pager
