--- # Matt Pocock 工程技能集 来自 [mattpocock/skills](https://github.com/mattpocock/skills) 的实战技能集合。 ## 工程技能 - **code-review** — 代码审查工作流，系统化审查代码变更
- **domain-modeling** — 领域建模，将业务需求转化为领域模型
- **grill-with-docs** — 基于文档的深度设计审查，同时生成 ADR 和术语表
- **improve-codebase-architecture** — 代码库架构分析与改进
- **setup-matt-pocock-skills** — 一键安装配置 Matt Pocock 全套技能
- **tdd** — 测试驱动开发工作流
- **to-issues** — 将需求讨论自动转化为 GitHub Issues
- **to-prd** — 将需求讨论转化为产品需求文档 (PRD)
- **diagnosing-bugs** — 系统化 Bug 诊断与根因分析
- **docker-optimization** — Docker 镜像优化与最佳实践
- **resolving-merge-conflicts** — 合并冲突智能解决
- **request-refactor-plan** — 重构方案制定 ## 生产力技能 - **grilling** — 深度追问思考，帮助你理清思路
- **grill-me** — 自我审查模式，主动质疑设计的薄弱环节
- **handoff** — 任务交接与上下文传递
- **teach** — 互动式教学，通过测验和实操练习传授知识
- **writing-great-skills** — 如何编写高质量的 SKILL.md ## 创意/其他 - **design-an-interface** — 接口/UI 设计
- **edit-article** — 文章编辑与润色
- **ask-matt** — 模拟 Matt Pocock 风格的编程建议
- **loop-me** — 持续迭代反馈循环
- **wayfinder** — 项目导航与方向探索
- **wizard** — 向导式任务处理
- **writing-beats/fragments/shape** — 写作系列技能
- **claude-handoff** — Claude Code 交接上下文 ## 使用方式 复制 `SKILL.md` 到 `.claude/skills/<技能名>/` 目录即可使用。
