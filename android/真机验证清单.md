# Android 客户端 · 真机视觉验收清单

> 本清单汇总历轮实现中「逻辑已编译/单测/装包实证通过，但观感需真机肉眼确认」的项。
> 设备：`8defe612`（小米，MIUI）。APK：`android/app/build/outputs/apk/debug/app-debug.apk`
> 安装：`adb install -r -t --user 0 app-debug.apk`
> 启动：`adb shell am start -n com.dogecode.mobile/.MainActivity`

## 前置条件（验收流样式项必需）

1. 电脑端起 CLI（交互模式，非 `-p`）+ `CLAUDE_CODE_MOBILE_BRIDGE=1`
2. `curl http://127.0.0.1:5680/mobile/session-info` 返回 JSON（否则重启 CLI）
3. 手机与电脑同一 WiFi；App 内「会话」页扫描并连上电脑会话
4. 按需开开关：设置 → 应用锁、语音播报、完成时语音、需批准语音

## 验收项

### A. 逐字打字机动画（阶段 3）
- [ ] 发一条消息，观察助手回复是否**逐字生长**（约 125 字/秒），而非整块出现
- [ ] 长回复时文字节奏是否自然、不闪、不卡
- 源码：`ChatAdapter.nextRevealLen` / `startTypewriter`（24ms/帧，3 字/帧）

### B. 屏幕常亮（生成期间）
- [ ] 发一条会跑较久的回复，期间**不**自动熄屏锁屏
- [ ] 回复定稿后屏幕恢复可自动熄屏
- 源码：`MainActivity.setScreenWake` / `onStreamDelta` / `clearStreamingState`

### C. 链接点击开浏览器
- [ ] 让 AI 回一条含 `http(s)` 的链接，链接变蓝可点
- [ ] 点按后用系统浏览器打开该网址
- 源码：`ChatAdapter.bind` 的 `autoLinkMask=WEB_URLS`

### D. 应用锁超时重锁
- [ ] 设置开「应用锁」+ 设备已设锁屏凭据
- [ ] 离开 App（Home/切到别的应用）超过 2 分钟
- [ ] 回来时弹出系统解锁界面（不是直接进内容）
- 源码：`MainActivity.maybeRelockOnReturn` / `APP_LOCK_TIMEOUT_MS=2min`

### E. 触觉反馈（震动）
- [ ] 发送消息时手机轻震一下
- [ ] 任务完成时轻震（即使关了语音播报也震）
- [ ] AI 需批准时轻震（强提示）
- 源码：`MainActivity.buzz`（30ms，`VibrationEffect.DEFAULT_AMPLITUDE`）

### F. 分屏多窗口
- [ ] 最近任务里长按 App 卡片 → 拖到屏幕一侧进入分屏
- [ ] 与别的应用左右分屏后，App 布局正常、不崩、可继续对话
- 源码：`AndroidManifest` `resizeableActivity=true`

### G. 草稿按会话隔离
- [ ] 会话 A 输入框打半截字，切到会话 B，B 输入框为空（不是 A 的字）
- [ ] 切回 A，半截字仍在
- 源码：`DraftStore` `draft_<sessionKey>`

### H. 剪贴板粘贴（更多菜单）
- [ ] 从别处复制一段文本
- [ ] App 内点「更多 → 粘贴剪贴板文本」
- [ ] 输入框为空时直接填入；非空时追加到末尾（不覆盖）
- 源码：`MainActivity.pasteFromClipboard`

### I. 双指缩放字号（既有，回归确认）
- [ ] 双指捏合改变正文字号，松手后保持
- 源码：`PinchZoom` / `ChatFragment.applyPinchZoom`

## 验证口径说明

- 上述 A/B/C/D/E/F 的**代码路径**已全部经 `logcat` 启动实证（无 FATAL EXCEPTION、
  无进程崩溃），但**观感**只有真机操作能确认。
- 若某项不符预期，优先 `adb logcat -c` → 复现 → `adb logcat -d > log.txt`，
  搜 `com.dogecode.mobile|AndroidRuntime|FATAL EXCEPTION` 取证。
- 小米特有 `FrameInsert open fail` 日志与本 App 无关（系统截图子系统），可忽略。
