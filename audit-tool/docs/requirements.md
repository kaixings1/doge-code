# 项目需求分析：工具与文档一致性检查

## 1. 目标分析
检查所有工具、命令以及源代码中的能力，对比说明文档，识别哪些能力未在文档中更新。

## 2. 输入
- 源代码目录（src/）
- 工具脚本目录（tools/）
- 命令定义文件
- 现有说明文档（README、docs/等）

## 3. 输出
- 未 documented 的能力清单
- 过时文档标识
- 更新建议报告

## 4. 约束
- 必须覆盖所有源代码文件
- 必须识别 CLI 命令、API 接口、配置选项
- 生成结构化报告（Markdown/JSON）

## 5. 成功标准
1. 完成全量代码扫描
2. 生成差异报告
3. 标识所有缺失项
