# 项目能力审计工具
## 项目简介
本工具用于扫描项目全量源代码、配置文件、脚本，提取其中使用的所有工具、命令及能力，对比项目文档中记录的项，找出未更新到文档中的缺失内容，帮助完善项目文档。

## 核心功能
1. **源码扫描**：遍历项目所有源代码文件，提取其中调用的系统命令、第三方工具、自定义脚本能力
2. **文档解析**：解析项目现有文档（Markdown、配置文件等），提取已记录的工具、命令、能力项
3. **差异对比**：对比扫描结果与文档记录，输出未在文档中体现的能力清单
4. **配置化扫描**：支持自定义忽略目录、文件后缀、扫描范围等规则

## 支持的扫描内容
- 源代码文件：`.sh`、`.py`、`.js`、`.ts`、`.go`、`.java`、`.c`、`.cpp`、`.md`、`.json`、`.yaml`、`.yml`、`.conf`、`.txt` 等
- 提取的能力类型：
  - 系统命令（如 `grep`、`awk`、`sed`、`curl`、`docker` 等）
  - 自定义脚本及函数
  - 第三方工具调用
  - 配置文件中的参数与能力定义

## 安装依赖
工具基于 Bash 开发，支持 Linux/macOS 系统，依赖如下：
- Bash 4.0+
- 基础系统命令：`find`、`grep`、`sed`、`awk`、`jq`（可选，用于JSON处理）
