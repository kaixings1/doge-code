name: research
description: 针对高可信度的一手资料调查问题，并将发现以 Markdown 文件形式保存在仓库中。当用户想要对某个主题进行研究、收集文档或 API 相关事实，或将阅读调研工作委派给后台 Agent 时使用。
---

启动一个**后台 Agent** 来进行研究，这样在它阅读的同时你可以继续工作。

它的任务是：

1. 针对**一手资料**调查问题——官方文档、源代码、规范、第一方 API——而不是它们的二手转述。将每个论断追溯到拥有该论断的原始来源。
2. 将发现写入单个 Markdown 文件，并为每个论断注明其来源。
3. 将文件保存在仓库中已有的存放此类笔记的位置；遵循现有惯例，如果没有惯例，则放在合理的位置并说明位置。
