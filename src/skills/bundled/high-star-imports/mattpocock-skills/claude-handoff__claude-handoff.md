---
name: claude-handoff
description: 将当前对话移交给一个全新的后台代理，让它立即接手工作。
argument-hint: "下一个会话将用于什么？"
disable-model-invocation: true
---

撰写一份当前对话的交接摘要，以便一个全新的代理能够继续这项工作。不要只是保存它，而是启动一个后台代理，并将该摘要作为其提示词（prompt）：`claude --bg --name "<描述性名称>" "<交接摘要>"`。它会在当前工作目录中启动并立即返回；用户可以通过 `claude agents` 来管理它。

始终传入 `-n`/`--name` 并附带一个描述性名称（例如 `--name "Fix login bug"`）——它会设置在任务列表、会话选择器和终端标题中显示的名称。

在摘要中包含一个 "suggested skills"（建议技能）部分，建议该代理应调用的技能。

不要重复其他工件中已记录的内容（PRD、计划、ADR、issue、提交、diff）。改为通过路径或 URL 引用它们。

脱敏任何敏感信息，例如 API 密钥、密码或个人身份信息——因为摘要会成为该代理的提示词。

如果用户传入了参数，请将其视为对下一个会话重点关注内容的描述，并据此调整摘要。
